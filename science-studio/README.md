# Science Learning Studio

โปรแกรมสร้างหลักสูตรวิทยาศาสตร์แบบแยกส่วน ไม่อ่านเอกสารต้นฉบับ โครงสร้างข้อมูลคือ `บท > EP > Part` และใช้ Gemini สร้างทีละงานเพื่อจำกัดบริบทและบันทึกความคืบหน้า

## Workflow

1. เลือกแขนง ระดับชั้น พื้นฐาน หัวข้อ และเป้าหมาย
2. Gemini วางบท ตามด้วย EP และ Part ทีละขั้น
3. ครูตรวจและแก้โครงก่อนยืนยัน
4. Gemini สร้างเนื้อหาทีละ Part และบันทึกหลังจบทุกงาน
5. ครูแก้ไขและตรวจรับแต่ละ Part
6. Gemini กระจายข้อสอบตาม Part ที่ผ่านตรวจและสร้างครั้งละไม่เกิน 3 ข้อ
7. โปรแกรมจัดแผนเรียนจากวันและเวลาที่ผู้เรียนเลือก

เมื่อคำตอบเนื้อหาเกินงบ Token โปรแกรมแบ่ง Part เป็นสองส่วนย่อยได้สูงสุดสองระดับแล้วทำต่อ มี lease ป้องกันเบราว์เซอร์หลายหน้าสร้างงานเดียวกันพร้อมกัน

ตาราง `science_projects` ถูกสร้างอัตโนมัติเมื่อเปิด API หรือสร้างล่วงหน้าด้วย `database/science_studio.sql` ได้ API Key ใช้ร่วมกับ Next Beyond ผ่าน `system_settings.gemini_api_key`
